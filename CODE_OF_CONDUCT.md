# Code of conduct

Treat contributors and users respectfully. Discuss technical evidence and behavior, welcome questions and corrections, and avoid harassment, threats, discriminatory language, personal attacks and publishing another person's private information.

This policy applies to repository issues, pull requests, reviews and project discussions. Maintainers may remove violating content, lock discussions or restrict participation according to the severity and context. They should explain decisions without exposing private reports and consider corrections or appeals fairly.

Report a concern to the maintainer [w3fans](https://github.com/w3fans). When private communication is needed, request a private contact without publishing personal details. A security vulnerability follows [SECURITY.md](SECURITY.md).
