## Persistent SFTP resume and encrypted SSH keys — 2026-10-11

Resume verifies the original authenticated host key, profile binding, source metadata and complete source digest, then compares the retained partial prefix before appending. It verifies the complete staged SHA-256 and original destination before commit. Changed source, destination, host key, profile, symlink, partial prefix or permissions are refused while existing data is preserved. Profile edits keep affected jobs visible with disabled actions until original settings are restored.

Overwrites preserve the reviewed original in a unique remote backup until verified commit cleanup. The commit phase is journaled before renames.
