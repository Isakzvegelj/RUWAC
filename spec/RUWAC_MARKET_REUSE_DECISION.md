# RUWAC retained foundation and component provenance

Desktop interaction and embedded RDP increment, 2026-10-10. Earlier reports are retained privately; this report supersedes their current-state claims.
No broad market analysis or multiplexer replacement was repeated. Existing RUWAC daemon remains the proven foundation. RustConn integration patterns were reviewed for tab/lifecycle and IronRDP APIs; its GPL-3.0-or-later source was not copied. No cmux-tui/Smithers code was imported.

New desktop, staging, split layout and RDP glue are original RUWAC implementation. GTK binding line remains gtk4 0.11.5/libadwaita 0.9.2. IronRDP and ironrdp-tokio are MIT OR Apache-2.0 libraries, pinned in the optional workspace lockfile; TLS uses native-tls and the system OpenSSL trust stack. Official IronRDP APIs and cached crate sources informed the original implementation. All transitive pinned license declarations are recorded in the public dependency inventory, with exact source-cache hashes retained privately.

There is no FreeRDP fallback at this stage: no measured real-host compatibility deficit yet justifies a second backend. Product distribution licensing and notices still require review before packaged distribution. Library declarations alone do not settle the product's distribution license.

Physical GNOME keyboard/touchpad/PRIMARY acceptance is unqualified. Weston does not provide PRIMARY. Real authenticated RDP requires an explicitly authorized endpoint, username, Secret Service profile and trusted server certificate/CA; none is designated. RDP CLIPRDR, dynamic remote resizing, clipboard image attachment acknowledgement, IME, accessible terminal semantics and RPM distribution remain unfinished. TUI copy remains bounded capture rather than the desktop interactive copy UI. Foreground/EOF terminal mouse and alternate-screen state reset is implemented; restoration of termios after an abruptly killed child is not certified. Daemon or host failure still loses in-memory sessions.
