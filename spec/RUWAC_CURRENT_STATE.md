# RUWAC current state

Embedded RDP, clipboard and machine-library increment, 2026-10-11, continuing the existing v0.1.2 release. The Rust daemon, canonical alacritty terminal state, authenticated Unix IPC, CLI, Screen navigation, persistent nested pane layout and 50,000-line bounded scrollback remain the foundation. Graphical/RDP dependencies remain confined to the optional desktop workspace.

Each native RDP tab has a worker-owned IronRDP connection, mandatory TLS/hostname validation, CredSSP/NLA, coalesced decoded framebuffer updates, scaling and input/modifier cleanup. Disposable loopback integration uses IronRDP server 0.13.0, generated credentials, an explicit generated CA and a generated 320×180 desktop. It exercises authenticated sessions and actual protocol decoding rather than the older negotiation-only mock. Transient TCP/stream failures get at most three reconnect attempts with 0.5/1/2-second backoff; certificate and authentication failures are not retried automatically.

CLIPRDR is registered as a static virtual channel and drives IronRDP's capabilities, format-list acknowledgement and format-data state machine. GDK CLIPBOARD and the selected tab exchange UTF-16LE Unicode text and PNG, with CF_DIB/CF_DIBV5 conversion through the existing IronRDP format component. Explicit UTF-8 MIME publication prevents GDK legacy text conversion. Five policies control direction: bidirectional, local to remote, remote to local, manual and off. Send/receive actions and acknowledged remote paste are provided. Neither PRIMARY nor the Screen internal buffer participates in RDP synchronization.

The collapsible machine sidebar has Ctrl+K search, favorites, recents, full group paths and tags. Explicitly selected Remmina files produce a read-only metadata preview; import stores only approved nonsecret fields in a private atomic JSON store. Passwords, private-key paths and certificate paths are excluded. RDP endpoints open native tabs; SSH endpoints create daemon-owned SSH PTYs asynchronously. No host discovery is performed.

Physical GNOME keyboard layouts, AltGr, touchpad gestures, IME and PRIMARY remain unqualified; the owned Weston compositor does not provide PRIMARY. No authorized external Windows or GNOME RDP endpoint was designated, so those host interoperability and physical-desktop gates remain blocked. Dynamic remote resolution/reactivation, panning a desktop larger than the native-pixel viewport, file/HTML clipboard transfer, agent attachment acknowledgement and qualified RPM distribution remain open. In-memory terminal sessions survive client exit, but not daemon or host failure. General abrupt-child termios recovery remains unqualified beyond the owned Bash/job-control regression. The machine library currently imports nonsecret metadata and opens endpoints; a full profile editor and Secret Service management UI are still needed. Product distribution licensing remains unresolved before binary packaging.
