# RUWAC embedded RDP, clipboard and machine library

This source prerelease adds authenticated in-window IronRDP sessions with verified TLS, bounded reconnects, decoded frames and bidirectional CLIPRDR text/PNG, including DIB/DIBV5 conversion. FocusBroker gates the selected tab and five clipboard policies; internal Screen buffers and PRIMARY remain separate.

The collapsible sidebar adds search, favorites, recents, groups/tags and explicit read-only Remmina metadata preview/import. RDP opens native tabs; SSH opens persistent daemon-owned terminals. The existing Rust engine, CLI and Screen workflow remain the foundation.

Validation uses actual authenticated loopback protocol sessions and a separate GDK peer on an owned Weston compositor. Generated credentials, desktop frames and synthetic input are explicitly distinguished from external Windows/GNOME and physical-desktop acceptance. See the current acceptance and integration reports for exact results.

Physical GNOME keyboard layouts, AltGr, touchpad gestures, IME and PRIMARY remain unqualified; the owned Weston compositor does not provide PRIMARY. No authorized external Windows or GNOME RDP endpoint was designated, so those host interoperability and physical-desktop gates remain blocked. Dynamic remote resolution/reactivation, panning a desktop larger than the native-pixel viewport, file/HTML clipboard transfer, agent attachment acknowledgement and qualified RPM distribution remain open. In-memory terminal sessions survive client exit, but not daemon or host failure. General abrupt-child termios recovery remains unqualified beyond the owned Bash/job-control regression. The machine library currently imports nonsecret metadata and opens endpoints; a full profile editor and Secret Service management UI are still needed. Product distribution licensing remains unresolved before binary packaging.
